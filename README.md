# Vertex Agents — Landing Page

Public landing page for **Vertex Sentinel**.

## Purpose

Explain the product, show proof, and capture early integrator / investor interest.

## Messaging

- Vertex Sentinel is the fail-closed execution layer for autonomous AI agents.
- Cryptographic intents, on-chain guardrails, and verifiable execution.
- Zero private-key delegation — agents sign intents instead of holding keys.
