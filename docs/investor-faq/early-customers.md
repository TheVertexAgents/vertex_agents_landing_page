# Early Customers — Vertex Sentinel

Target buyer groups
- AI agent platforms issuing SDKs with execution capabilities
- exchanges and brokerages exposing MCP/agent execution endpoints
- fintech bots and robo-advisors needing compliant trade authorization
- enterprise workflow agents with procurement, purchasing, or disbursement actions
- DeFi protocols integrating autonomous agents and needing policy enforcement

Use cases to validate first
- Kraken MCP agent trading with cryptographic intent authorization
- enterprise procurement agent with spend limits, vendor allowlists, and deadline controls
- payments/sub-agents with microtransaction authorization trails

Validation plan
- publish live execution proof and ask integrators to run the SDK
- target 3–5 developer conversations in the chosen segment before expanding messaging
- offer “Sentinel Preview” access: sandboxed RiskRouter with their workflow schema

Pricing direction
- integration/SDK access fee or platform-side revenue share
- enterprise risk-policy customization and chain/registry deployment
- audit/verification export as a compliance deliverable
